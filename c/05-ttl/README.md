# 05 — TTL (Time-to-Live)

Demonstrates key expiration using TidesDB's TTL support.

## What This Covers

- Inserting keys with TTL values
- Verifying keys exist before expiration
- Observing automatic key expiration
- TTL behavior across compaction

## Build & Run

```bash
make        # from c/ directory: make 05-ttl
./05-ttl
```
