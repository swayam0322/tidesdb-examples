# 02 — Column Families

Explores creating, configuring, and managing multiple column families in TidesDB.

## What This Covers

- Creating column families with different configurations
- Per-family compression settings (Snappy, LZ4, Zstd)
- Writing and reading data across families
- Dropping column families

## Build & Run

```bash
make        # from c/ directory: make 02-column-families
./02-column-families
```
